## Project structure:
```
--copycat
   |--client
   |--server
   |--db-data
```
**copycat** - project root folder, contains everything

**client**  - contains frontend code, our frontend is written in Vue and deployed with Vite 

**server**  - contains backend code, written in Java Skript

**db-data** - this is where you can put database files, it wont be necessarily that important, but it's there just in case

For installation and usage instructions, please visit the [how-to guide](how-to.md).
